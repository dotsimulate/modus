MODUS
Your MO for working with AI agents

Personal infrastructure designed to be forked and customized. A locally configured agent wrangler built on the Claude Agent SDK with concurrent sessions, configurable profiles, persistent memory, and live streaming UI.

Core Features

Everything you need to work effectively with AI agents

🎛️ Agent Profiles

JSON-based configuration for model, tools, prompts, permissions, and MCP servers. Customizable per agent or user.

💾 Persistent Memory

FastMCP/Python memory server with query() and save() for cross-session learning and knowledge persistence.

🎯 Session Management

Concurrent agent sessions with state persistence, UI streaming, and real-time collaboration tracking.

🎤 Voice Commands

Whisper transcription integration with voice-driven agent steering and audio playback capabilities.

🎨 Live Streaming UI

React 19 frontend with Vite, theme-aware colors, recording state visualization, and responsive panel layouts.

⚙️ Scheduled Automation

Action system with timer-based execution, webhook triggers, and cross-agent orchestration capabilities.
